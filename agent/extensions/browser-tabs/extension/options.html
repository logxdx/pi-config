Pi Browser Bridge

Contents of ~/.config/pi-browser-tabs/token (created the first time pi starts the bridge).
Each pi session uses the first free port from here up (10 ports, so up to 10 parallel sessions). Must match PI_BROWSER_PORT in pi. Default 17420.
Off by default: pi can list tab titles and URLs, but only reads or acts on tabs you share with the toolbar button (or that pi opened itself).
